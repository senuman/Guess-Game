## 🛠 **Installation & Usage**

### **Quick Start**
```bash
# Clone or download the system files
python3 ultimate_ai_music_system_implementation.py

# The system will automatically load and demonstrate:
# 1. Basic Pop Song Analysis
# 2. Thai Cultural Context Analysis
# 3. Elderly Singer Simulation
```

### **Custom Analysis**
```python
from ultimate_ai_music_system_implementation import UltimateAIMusicSystem, ProcessingDepth, Platform

# Initialize system
system = UltimateAIMusicSystem()

# Analyze with human factors
human_factors = {
    'age': 55,
    'confidence_level': 8.5,
    'cultural_authenticity': 9.2,
    'emotional_state': 7.8
}

# Run analysis
result = system.analyze_song(
    song_input="title: Your Song\nYour song description here",
    depth=ProcessingDepth.DEEP,
    cultural_context="thailand_luk_thung",
    human_factors=human_factors,
    target_platform=Platform.SUNO_AI
)

# Display with terminal colors
system.display_analysis(result, Platform.SUNO_AI)
```
